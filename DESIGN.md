# Design
Established world: Tower Arcade. Inherit its dark surfaces, readable system sans typography (explicit user preference), warm/cool per-game accents, and JDEVO attribution. These are game detail pages, not a replacement visual identity. No images, SVG illustrations, background artwork, video, icon fonts, external fonts or media dependencies.

Use a text-led page: quiet navigation, prominent game name, concrete one-sentence premise, readable overview, ordered play steps, a definition-list control guide, plain development status, and a compact footer. Avoid repeated cards, decorative labels and fake Play buttons. Background #0b1016, foreground #f1f4ea, secondary #bac7bf, rules #354038. Game accents match the hub: Boom Boom Tower #ffac88, Cointraptions #f3d575, Orble #92caff. Headings use the same system family; body 16px with generous line height. Content max 1120px, text measure 65ch; collapse two-column content on phones, keep 44px navigation targets and visible keyboard focus. Use no unsolicited motion.
